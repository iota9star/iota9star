## 👨‍💻 About Me

I'm a full-stack developer with a product mindset 🧠: I don't ask "what can I build?" but "what will people feel when they use it?" — then I build the whole path to that feeling, backend to pixel.

- ⚙️ **Backends that stay calm** — Rust (Axum) and Java (Spring) microservices tuned for the virtues nobody tweets about: steady latency, honest errors, logs that still make sense at 3 a.m. 🌙
- 📱 **Flutter as a craft** — a dozen packages under the [FlutterCandies](https://github.com/fluttercandies) banner 🍬, each one carved out of a real production problem, not a portfolio itch
- 🦀 **Rust where it shouldn't fit** — a JavaScript engine living inside a Flutter widget tree, and signal-based reactivity pulled straight into Dart ⚡
- 🧑‍🎨 **Frontends with taste** — React, Vue and Android screens refined until the interface disappears and only the result remains 🍃
- 🤖 **AI as a co-worker, not a novelty** — agents draft, I direct; the quality gates stay on and every merge still passes through human judgment ✅
- ⛓️ **Web3 with receipts** — BTC, EVM and Internet Computer; I read the protocol's source before I trust its promises 🔑

🔭 **On the workbench:** a Rust-powered JS runtime shrinking into Flutter, a signals library tuned for raw reactivity, and TV navigation smooth enough to operate from the couch 📺.

## 💭 Philosophy

- 🧩 Small, sharp pieces win — a library that does one thing well outlives a framework that does everything badly
- 🛡️ Let the compiler carry the documentation: types that can't rot beat comments that will
- 🎨 Polish is a feature — the last 5% is the part people actually remember
- 🔍 Read the error message, then read it again; it is usually telling the truth
- 🚢 Ship, measure honestly, delete without mercy
- 🤝 Every issue is a person who cared enough to write in — answer like it
- 🧭 Stay small, stay sharp, stay shipping — the stack rewards precision ⚡
