## 👨‍💻 About Me

Hi, I'm **iota9star** — I build digital experiences across the whole stack, from high-performance backends to interfaces people genuinely enjoy touching.
On the server I lean on **Rust** 🦀 and **Java** ☕ for speed and reliability; on the client I reach for **Flutter** 📱, **React**, and **Vue** to make that speed feel effortless.
I treat product thinking as an engineering skill rather than a department — the best code is the code that ships the right thing. 🎯
These days I'm fusing **Rust into the Flutter ecosystem** ⚡, shipping open-source packages with the **fluttercandies** org 🍬, and weaving **AI agents** 🤖 into my everyday workflow.
Off the clock you'll find me tracking seasonal anime 🎬, wandering Bitcoin and EVM rabbit holes ⛓️, and rewriting things that already worked — just faster.
