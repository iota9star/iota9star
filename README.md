### 👨‍💻 About Me

Hi, I'm **iota9star** 🌟 — a full stack developer who treats the whole stack as one canvas 🎨  
I write fast, memory-safe backends in Rust 🦀 and battle-tested services in Java ☕, then wrap them in Flutter frontends that feel right at home on any screen 📱  
Product mindset above all: I care about the last 5% — the animation curve, the error message, the empty state ✨  
Off the clock you'll find me publishing open source candy 🍬 at [fluttercandies](https://github.com/fluttercandies), tinkering with reactive signals ⚡, or mapping the Web3 landscape ⛓️

### 🎯 What I Do

- 🦀 **Rust & Java Backends** — Axum + Spring microservices built for throughput and uptime
- 📱 **Cross-Platform Apps** — Flutter, React, Vue, and Android, one codebase at a time
- 📦 **Open Source Maintainer** — a shelf of published packages serving the Flutter ecosystem
- 🤖 **AI-Augmented Engineering** — agents, code assistants, and quality-first automation
- ⛓️ **Web3 R&D** — BTC primitives, EVM contracts, and Internet Computer canisters
- 🔬 **Reactive Systems** — fine-grained signals and state graphs in Dart
