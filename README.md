## 👨‍💻 About Me

Full-stack developer with a product brain 🧠 and a mild hoarding problem for production scars — anything that bites me twice gets exorcised into a package small enough for a stranger to adopt with a single `pub add` 📦.

- ⚙️ **Boring on purpose** — Axum and Spring services tuned for flat latency, truthful errors, and logs that still make sense at 3 a.m. 🌙
- 🍬 **FlutterCandies regular** — 12 published packages, each one extracted from a real app that needed it: TV remotes, type-safe routing, immutable clocks, honest error types
- 🦀 **Rust where you least expect it** — a QuickJS-powered JavaScript runtime living inside Flutter, and alien-signals reactivity ported to Dart at bare-metal speed ⚡
- 📺 **Fan first, engineer a close second** — my display name is borrowed from an anime I love, and I've built three clients for the communities I actually live in (Mikan Project, DMHY, Ailian BT); three languages, one decade of fandom 💜
- 🤖 **AI-native builder** — agents write the first drafts, I direct the edit; nothing ships until a human signs off ✅
- ⛓️ **Web3 with the covers off** — BTC, EVM and Internet Computer; I read the protocol source before I trust any whitepaper 🔑

🔭 **Currently in orbit:** pushing the Flutter-embedded JS runtime harder, tuning signal-based reactivity toward zero-cost updates, and keeping a D-pad responsive enough to run a living room from the couch 🛋️.  
🤝 My profile bio reads 我们，有些许相似 — *"we're somewhat alike."* If that lands, we'll get along.
