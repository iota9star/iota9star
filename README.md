## 👨‍💻 About Me

Years of tending code have taught me that orchards don't die from one big storm — they die from a thousand small neglects 🍂. So I show up for the small stuff, every day.

- 🏗️ **Backend by profession** — Axum & Spring microservices kept like well-irrigated soil: steady, boring in the best way, ready under load 🌾
- 🍎 **Flutter orchard-keeper** — a dozen packages fruiting under the [FlutterCandies](https://github.com/fluttercandies) banner, each one grown from a real project's need, not a whim 🍬
- 🧑‍🎨 **Frontend by taste** — React, Vue and Android interfaces pruned until interaction feels effortless, like wind through leaves 🍃
- 🤖 **AI-augmented by default** — agents handle the watering; I still do the grafting. Every quality gate stays human-reviewed ✅
- ⛓️ **Web3 by curiosity** — BTC, EVM & Internet Computer; I read the roots of a protocol before I trust its fruit 📜

🌳 **Currently in the greenhouse:** a JavaScript engine burning Rust inside Flutter 🦀, fine-grained signals for Dart 📡, and TV D-pad navigation precise enough for the living-room couch 📺.

- 🧩 Small, sharp pieces win — a library that does one thing well outlives a framework that does everything badly

- 🎨 Polish is a feature — the last 5% is the part people actually remember

- 🚢 Ship, measure honestly, prune without mercy
