## 👨‍💻 About Me

Hi, I'm **iota9star** — a full-stack developer who treats every millisecond as a design decision. ⚡  
My home turf is the backend: **Rust** 🦀 services that scream, **Java** ☕ ecosystems that scale, and microservices that stay boring at 3 a.m.  
Up front, I build with **Flutter** 📱, **React** ⚛️, and **Vue** 💚 — because users judge software by how it feels, not by its architecture diagrams.  
A product mindset means I ask *why* before *how* — the roadmap is part of the codebase. 🎯  
Right now I'm deep in **Rust ↔ Flutter interop** with the **fluttercandies** crew 🍬 and teaching **AI agents** 🤖 to write the boring parts.  
Off duty: seasonal anime 🎬, BTC / EVM / IC rabbit holes ⛓️, and profiling things that were already "fast enough." 🔬
