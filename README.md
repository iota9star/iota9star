## 👨‍💻 About Me

A full-stack developer who treats every problem that bites twice as a candidate for extraction: if it hurt in two codebases, it becomes a package with docs, tests, and a semver promise 📦.

- 🏗️ **Boring where it counts** — Axum and Spring services tuned so the latency graphs stay flat and the pager stays dark; the excitement belongs in the product, not the infrastructure 😴
- 🍬 **12 packages under the [FlutterCandies](https://github.com/fluttercandies) banner** — D-pads for TVs, immutable clocks, concurrency limits, honest error types; each one escaped from a real app that needed it 🚪
- 🦀 **Rust × Dart bridge-builder** — a QuickJS-powered JavaScript runtime living inside Flutter, and alien-signals reactivity ported to Dart; two languages, one friendship 🤝
- 📺 **Fan first, engineer a close second** — three clients for the anime communities I actually live in (Mikan Project, DMHY, Ailian BT), written in three languages across a decade of fandom 💜
- 🤖 **AI-native builder** — agents write the first drafts, I direct the edit; the merge button only moves when a human is satisfied ✅
- ⛓️ **Web3 with the covers off** — BTC, EVM and Internet Computer; I read the protocol source before I believe any whitepaper 🔍

🔭 **Currently:** pushing the Flutter-embedded JS runtime harder, tuning signal-based reactivity toward zero-cost updates, and keeping a D-pad responsive enough to run a living room from the couch 🛋️.  
🤝 My profile bio reads 我们，有些许相似 — *"we're somewhat alike."* If that lands, we'll get along.

## 💭 How I Work

- 🧩 Small is a feature — a library you can read in one sitting is a library you can trust
- 🧠 If a human has to remember it, teach the type system instead
- 🐢 Speed is a feature; predictable speed is a promise
- 🚢 Ship the version that teaches; keep the perfection for the API
- 🪞 Review your own diff as a stranger would — future you qualifies
- 📐 Constraints aren't the enemy of design; they are the design
- 🤝 Every issue is someone who cared enough to write in — answer kindly
