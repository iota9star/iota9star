## 👨‍💻 About Me

The name is the plan. 🌟 *Iota* is the smallest unit there is — *star* is what small things become when you refuse to stop polishing them. Almost everything I've shipped started as one tiny function someone needed, including me.

Day to day I live on the server, writing **Rust and Java**: Axum services, Spring microservices, queues, dashboards, the unglamorous machinery that only gets noticed when it breaks. 🏗️ But software is judged at the pixel, not the endpoint, so I keep a hand in **Flutter, React, Vue, and Android** too. A 40 ms p99 means nothing to a user who tapped a button that felt dead.

Most of my open-source hours go somewhere quieter: 🤫 small, type-safe, dependency-lean packages — routing, date-time math, concurrency limits, error handling, codegen — the kind of code that nobody thinks about until it isn't there. Twelve of them live under [fluttercandies](https://github.com/fluttercandies), and across my own projects they've collected **1,700+ ⭐** from people I'll never meet. Still the best kind of surprise.

## 🧭 How I Build

- 🎯 **Product first** — code is a means; the end is a person finishing something they cared about.
- 🪨 **Let the compiler carry it** — if a type can hold the invariant, don't hold it in your head instead.
- ⚡ **Performance is UX** — fast software feels respectful; slow software spends someone else's life.
- 🔁 **Ship small, ship often** — a working 80% in real hands beats a perfect 100% on a branch.
- 🧹 **Boring is a feature** — the best dependency is the one you forget you installed.
- 🤝 **Open by default** — the best bug reports come from someone who isn't you.
